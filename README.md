# AI Slops Hunter

AI Slops Hunter убирает из работы AI то, что обычно приходится править вручную: воду в текстах, лишнюю сложность в коде и неясные формулировки в интерфейсах. Скилл находит конкретные недостатки и по вашей просьбе исправляет их, сохраняя смысл, авторский голос и поведение программы. Работает в Claude Code, Codex и других агентах с поддержкой скиллов.

## Установка

При установке выберите своего агента.

Глобально, для всех проектов:

```bash
npx skills add svishniakov/ai-slops-hunter --global
```

В текущий проект, из его корневой папки:

```bash
npx skills add svishniakov/ai-slops-hunter
```
