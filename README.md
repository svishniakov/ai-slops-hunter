# AI Slops Hunter

AI Slops Hunter убирает из работы AI то, что обычно приходится править вручную: воду в текстах, лишнюю сложность в коде и неясные формулировки в интерфейсах. Скилл для Codex находит конкретные недостатки и по вашей просьбе исправляет их, сохраняя смысл, авторский голос и поведение программы.

## Установка

Глобально, для всех проектов:

```bash
npx skills add svishniakov/ai-slops-hunter --agent codex --global
```

В текущий проект, из его корневой папки:

```bash
npx skills add svishniakov/ai-slops-hunter --agent codex
```
