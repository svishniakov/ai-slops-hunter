# AI Slops Hunter

Скилл для Codex, который находит воду, шаблонные формулировки и лишнюю сложность в готовой работе. Проверяет тексты, документацию, код, тесты и интерфейсы. По запросу вносит правки, сохраняя смысл, авторский голос и поведение программы.

Выделен из роли `ai-slops-hunter` проекта [Agent Flow](https://github.com/svishniakov/agent-flow). Исходная роль остаётся в Agent Flow. Эта версия работает самостоятельно и развивается отдельно.

## Установка через npx

Потребуются Node.js 22.20.0 или новее, npm и Git. Установкой управляет [Skills CLI](https://github.com/vercel-labs/skills), который получает скилл прямо из этого GitHub-репозитория. Публиковать отдельный npm-пакет не требуется.

Установить для Codex во всех проектах:

```bash
npx skills add svishniakov/ai-slops-hunter --agent codex --global
```

Установить только в текущий проект, выполнив команду из его корня:

```bash
npx skills add svishniakov/ai-slops-hunter --agent codex
```

Для выбора другого поддерживаемого агента в интерактивном терминале:

```bash
npx skills add svishniakov/ai-slops-hunter
```

`--global` задаёт установку для пользователя; без него скилл устанавливается в проект. Параметр `--yes` в конце команды пропускает подтверждения Skills CLI. При первом запуске npm может отдельно предложить загрузить пакет `skills`.

Начните новую задачу Codex и вызовите `$ai-slops-hunter`. Скилл также доступен для автоматического выбора по подходящему запросу. Формат вызова в других агентах зависит от их интерфейса.

### Проверка, обновление и удаление

Посмотреть содержимое репозитория без установки:

```bash
npx skills add svishniakov/ai-slops-hunter --list
```

Обновить глобальную установку:

```bash
npx skills update ai-slops-hunter --global
```

Обновить установку в текущем проекте:

```bash
npx skills update ai-slops-hunter --project
```

Удалить глобальную установку из Codex:

```bash
npx skills remove ai-slops-hunter --agent codex --global
```

Для удаления из текущего проекта уберите `--global`. После обновления начните новую задачу.

Если вы уже установили скилл через `git clone`, эта копия по-прежнему обновляется командой `git pull --ff-only` из её каталога. Перед переходом на Skills CLI сохраните локальные изменения; не устанавливайте новую копию поверх отредактированной вручную.

## Использование

Проверить без изменения файлов:

```text
$ai-slops-hunter проверь README.md на воду и шаблонные формулировки.
Верни замечания. Файл не меняй.
```

Убрать лишнее из кода:

```text
$ai-slops-hunter почисти изменения в src/components/Checkout.tsx.
Сохрани поведение, публичные API и принятый дизайн. Запусти нужные проверки.
```

Отредактировать текст:

```text
$ai-slops-hunter перепиши текст ниже короче и яснее.
Сохрани факты, оговорки и мой тон. Верни только готовый текст.
```

Проверить интерфейс:

```text
$ai-slops-hunter проверь приложенный экран оформления заказа.
Найди общие формулировки и лишние элементы. Дизайн не меняй, дай замечания.
```

«Проверь» означает ревью без правок. «Исправь», «почисти» и «перепиши» разрешают изменения указанного материала. Если материал уже хорош, скилл может оставить его без изменений.

## Что проверяет

| Материал | На что смотрит |
| --- | --- |
| Тексты и документация | Повторы, канцелярит, пустые обещания, неподтверждённую конкретику |
| Код | Очевидные комментарии, лишние обёртки, сложные условия, общие имена |
| Тесты | Проверки без полезного результата, повторение реализации, лишние заглушки |
| UI | Общие тексты, фиктивное содержимое, украшения, мешающие пользователю |
| Правила агентов | Дублирование, противоречия, обязательные этапы без ясной пользы |

Замечания должны опираться на конкретные фрагменты. Отдельное слово, стиль оформления или популярный компонент не доказывают низкое качество или использование AI.

## Как устроен

- [SKILL.md](SKILL.md) содержит все рабочие инструкции и критерии.
- [agents/openai.yaml](agents/openai.yaml) задаёт название и подсказку для интерфейса Codex.
- [LICENSE](LICENSE) сохраняет лицензию MIT и авторство исходного проекта.

Исполняемый код, API-ключи, MCP-серверы, Agent Flow и дополнительные скиллы не требуются. Codex выполняет инструкции в текущем агенте с выбранной пользователем моделью. Проверка файлов и экранов зависит от доступных инструментов среды.

Скилл не переключает модель и не запускает отдельного субагента. При переносе сохранены назначение и ограничения исходной роли; критерии проверки включены в сам скилл вместо обязательных ссылок на другие скиллы.

## Границы проверки

Скилл сохраняет факты, оговорки, поведение, публичные API, формат данных и принятый дизайн. Изменения за этими границами требуют отдельного поручения. Проверка на шаблонность не заменяет тестирование продукта, аудит безопасности или полноценное ревью дизайна.

Результат содержит замечания или описание правок, выполненные проверки и оставшиеся ограничения. Для формального отчёта предусмотрены `pass`, `pass-with-risks`, `fail` и `blocked`; точные значения описаны в [SKILL.md](SKILL.md).

Скилл не определяет авторство по стилю, не оценивает «процент AI» и не предназначен для обхода детекторов.
